# Writer Submission Structure

> **Status: Task-derived draft — pending editorial approval.**
> This defines the task-required export fields only. It is not an approved writer submission sample and contains no example article prose.

## Metadata block

- H1
- Meta title
- Meta description
- Open Graph title
- Open Graph description
- URL slug
- Page type (`blog`)
- Primary keyword
- Related keywords
- Locales required for later translation
- Date

## Body copy

- Body markdown in the approved blog structure.
- Internal links shown inline with their anchor text and target.
- Inline image markers with the proposed image filename and alt text.

## FAQ

- Three to six questions.
- Each answer is 40–80 words.

## Schema requirements

- Include the standing schema requirements for the blog page type.
- The exact approved schema template remains pending editorial/technical input.

## Translation handoff

- Include a checklist of translatable elements for development.
- The app does not translate content.

## Fact-check table

For each extracted claim, show:

- Claim text
- Claim type
- Source
- Verification status
- Content location
- Whether operator review is mandatory

Unverified, contradicted, provenance and designer-attribution items must remain visible.
